# MARBERTv2 Multi-Task Experiment

## Experiment Identity

- Run ID: marbertv2-multitask-kendall-lr2e5-confirmation-v1
- Model: UBC-NLP/MARBERTv2
- Architecture: Shared Encoder with Four Task Heads
- Loss: Kendall Uncertainty-Weighted Multi-Task Loss
- Learning Rate: 2e-5
- Dataset Version: v2
- Validation Seeds: 42, 1337, 2023, 7, 99

## Tasks

1. Complaint Category
2. Complaint Urgency
3. Customer State
4. Churn Risk
