# MARBERTv2 Multi-Task Error Analysis

## Scope

Research analysis of the five-seed validation
results for the MARBERTv2 multi-task experiment.

## Contents

- Error analysis report
- Task-level error statistics
- Root cause hypotheses
- Proposed remediation experiments

## Evaluation Boundary

All findings are based on validation data.
The final test set was not evaluated.

Proposed remediation experiments are hypotheses
for future investigation, not confirmed improvements.
